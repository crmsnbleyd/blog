Setting up a Common Lisp Editing Environment

Posted on Jul 28, 2025 in blogpost

Install SBCL

sudo apt install sbcl

download https://beta.quicklisp.org/quicklisp.lisp

sbcl --load quicklisp.lisp

(quicklisp-quickstart:install) (ql:add-to-init-file)

Install CLOG?

I will have to learn how to get asdf up with this

(ql-dist:install-dist "http://dist.ultralisp.org/"
                      :prompt nil)

sbcl --eval "(ql:quickload :clog/tools)" --eval "(clog-tools:clog-builder)"

Install Pulsar

https://pulsar-edit.dev/download.html

The regular install is fine.

I have an image already called pulsar-repl in the images folder

Download slime

SLIME is a Lisp program that allows Pulsar to interact with Lisp. Get the first zip file from https://github.com/slime/slime/releases and unzip it somewhere you would’t accidentally delete it. We will need it throughout our Lisp journey
