Lua for browser scripting, a completely made-up history

Posted on Apr 24, 2024 in blogpost

@foone@digipres.club

There's an alternate universe where Netscape Navigator embedded Lua instead of inventing JS, and I'm not sure if that's a better world or not.

What follows is a history of the most popular programming language in the world, Lua.

  • In 1995, Brendan Eich has been asked to develop a scripting language for Netscape Navigator. 10 days later, he is done with a wonderful language where every number is floating point and "1" + 1 is "11", but before he can show anyone his awesome creation, he is hit by a truck. Netscape uses Lua in their browser instead.
  • Microsoft makes VLua a new dialect in IE, nobody seems to like it, but they have to use it while IE is the most popular browser in the world.
  • Netscape releases an enterprise server software with the ability to write scripts in Lua, adding a bunch of libraries to it that makes it more batteries included. It however does not do as well as Microsoft's offering which uses VBScript.
  • Lua on Rails is developed, a complete framework that includes .el, embedded lua that is used to template HTML. It sort of copies both PHP and the Netscape thing but it's open source and not PHP, so it becomes very common. The world never learns who DHH is.
  • Facebook is built on server-side Lua, and finds it too slow so make their own compiler for Lua for a VM they've developed.
  • Moon, a new language that transpiles to Lua is developed by a group of disgruntled developers who would rather be programming in Haskell. Many codebases, including Github switch to it.
  • Microsoft makes TypeLua, which is another language that compiles to Lua. Developers everywhere hail it as a perfect language and ditch Moon en masse. Many codebases, including Github switch to it.

Like early js, lua has object oriented capabilities, with a prototype-based class system.

Some web scripters make luakit, which adds a capable standard library to lua, we also avoid callback hell since lua supports coroutines
