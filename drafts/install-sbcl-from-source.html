Installing Steel Bank Common Lisp from source

Posted on Jan 26, 2025

Step 1: Install ECL from source :: It’s written in C, and you already have a C compiler. git clone https://gitlab.com/embeddable-common-lisp/ecl.git --depth=1. ./configure --prefix=$HOME/.local (or whatever you want) then make then make install

./make-config.sh --xc-host="ecl --shell" --fancy --prefix=$HOME/.local
