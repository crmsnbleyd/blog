Subsetting my fonts to speed up page loads

Posted on Jan 10, 2025 in blogpost

Subsetting a font means to remove all the characters you don’t actually use in order to reduce the size of the files. My site theme uses the font-awesome icon font, which maps code points to tiny images like the mastodon logo for example. I only use 4 of these, so the thousands of other icons is just unnecessary data that viewers have to download.

I will be using a js package called glyphhanger, which in turn uses the python library fonttools

  1. Use npm or pnpm to install glyphhanger globally: pnpm add -g glyphhanger or npm install -g glyphhanger
  2. Use pipx to install fonttools into its own virtual environment (you can install pipx via your package manager or via pip) pipx install fonttools
  3. Install compression libraries for use by glyphhanger into the fonttool environment: pipx inject fonttools zopfli brotli.
  4. Move to the directory with your fonts and execute: glyphhanger 'https://drewsh.com' --subset='*.ttf'. This will subset all fonts with the .ttf extension based on what is used in drewsh.com. You can also give a path to HTML files if you haven’t published the site yet.
  5. You will get a bunch of files ending with -subset and then the extension, which you can use in your site.
